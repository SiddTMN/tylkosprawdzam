## Jednorazowe odświeżenie bez crona i bez publikacji

Aktualny `data/crypto-auto.json` pochodzi z 13.10 i przekracza próg świeżości 36 godzin. Sam sukces walidacji struktury nie odnawia weryfikacji. Nie uruchamiaj produkcyjnego `update-crypto-calendar.cjs` bez flag ani dispatch kolektora. Poniższy lokalny podgląd używa wyłącznie trzech wdrożonych kanałów GitHub z przypiętymi licencjami, nie pobiera ICS/Events CMS. Tworzy nowy katalog przy każdym uruchomieniu i nie nadpisuje poprzednich audytów ani żadnego `data/`.

Z korzenia repozytorium, w PowerShell:

```powershell
$env:CRYPTO_REFRESH_DIR = Join-Path 'docs/crypto-calendar-hybrid/preview' ('predeploy-' + [Guid]::NewGuid().ToString('N'))
@'
const fs=require('node:fs/promises'),path=require('node:path');
const {updateScheduled,validateFile}=require('./scripts/update-crypto-calendar.cjs');
const registry=require('./scripts/crypto-calendar/sources.cjs');
(async()=>{
 const outputPath=path.resolve(process.env.CRYPTO_REFRESH_DIR,'crypto-auto.json');
 const candidate=await updateScheduled({outputPath,approvedSourceIds:registry.map(s=>s.id)});
 await validateFile(outputPath); // także zgodność z rzeczywistymi wpisami ręcznymi
 const proof=JSON.parse(await fs.readFile(path.join(path.dirname(outputPath),'crypto-auto-verification.json'),'utf8'));
 if(!proof.passed||proof.generatedAt!==candidate.generatedAt||Object.values(candidate.sources).some(s=>s.status!=='fresh'))throw Error('Wszystkie trzy źródła muszą przejść świeży odczyt i licencje');
 console.log(JSON.stringify({candidate:outputPath,generatedAt:candidate.generatedAt,counts:proof.counts,events:candidate.events},null,2));
})().catch(error=>{console.error(error.message);process.exitCode=1;});
'@ | node
if ($LASTEXITCODE -ne 0) { throw 'Kandydat nie przeszedł kontroli. Nie kopiuj go do data/.' }
```

Przejrzyj `crypto-auto-verification.json`: HTTP 200 i potwierdzony SHA treści/licencji dla każdego źródła, odrzucone rekordy, paginację i liczby. Następnie sprawdź każde wydarzenie w jego źródle, termin, status, autorski opis i oznaczenia licencji. Zero przyszłych wydarzeń jest prawidłowym wynikiem; nie uzupełniaj go fikcyjnymi pozycjami ani rekordami z pilota. Nie opublikowano adapterów BTC/DOT/ATH/BONK.

**Dopiero po przeglądzie człowieka**, zachowując ten sam katalog w zmiennej, można lokalnie podmienić sam auto JSON. Przed kopiowaniem poniższy blok ponownie sprawdza dowód, bieżącą zgodność z ręcznymi korektami i limit jednej godziny od wygenerowania (dodatkowy warunek wydania, ostrzejszy od progu UI). Jeśli przerwa była dłuższa, wygeneruj nowy kandydat i powtórz przegląd.

```powershell
@'
const fs=require('node:fs/promises'),path=require('node:path');
const {validateFile}=require('./scripts/update-crypto-calendar.cjs');
(async()=>{
 const dir=path.resolve(process.env.CRYPTO_REFRESH_DIR),file=path.join(dir,'crypto-auto.json');
 const candidate=await validateFile(file),proof=JSON.parse(await fs.readFile(path.join(dir,'crypto-auto-verification.json'),'utf8'));
 if(!proof.passed||proof.generatedAt!==candidate.generatedAt||Date.now()-Date.parse(candidate.generatedAt)>3600000||Object.values(candidate.sources).some(s=>s.status!=='fresh'))throw Error('Odśwież kandydat i ponów przegląd');
 await fs.copyFile('data/crypto-auto.json',path.join(dir,'previous-crypto-auto.json'),fs.constants.COPYFILE_EXCL);
 await fs.copyFile(file,'data/crypto-auto.json');
 console.log('Podmieniono wyłącznie lokalne dane auto; bez commita i publikacji');
})().catch(error=>{console.error(error.message);process.exitCode=1;});
'@ | node
if ($LASTEXITCODE -ne 0) { throw 'Odświeżenie lokalne przerwane; nie publikuj.' }
node scripts/update-crypto-calendar.cjs --validate
if ($LASTEXITCODE -ne 0) { throw 'Walidacja nie przeszła; nie publikuj.' }
node --test tests/*.test.js
if ($LASTEXITCODE -ne 0) { throw 'Testy nie przeszły; nie publikuj.' }
```

Nie ustawiaj żadnej flagi `*_ENABLED=true`. Te polecenia nie zapisują danych makro/ręcznych, nie commitują, nie wysyłają zmian ani nie wdrażają strony. Do wydania nadal potrzebne są kontrola diffu, artefaktu i osobno zatwierdzone działania Git. Nie wykonano tych bloków podczas niniejszego audytu.
